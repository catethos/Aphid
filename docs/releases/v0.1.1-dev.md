# Aphid 0.1.1-dev — stability and correctness

Experimental prerelease containing five narrowly scoped LadybugDB fixes:

- Align packed FLOAT/DOUBLE sort-key and graph-path identifier accesses.
- Avoid overflowing intermediate INT128 addition and negation operations.
- Initialize ALTER defaults safely when an operator has no input result set.

New tests combine indexed transaction mutation with retained FTS, vector and
DuckDB cursors across timeout, caller death, shutdown, index rebuild and persistent
reopen. All 99 public tests pass on macOS against normal and fatal ASan/UBSan native
builds. Both native Linux architectures also pass all 99 tests in source-build,
relocated-bundle and fresh compiler-free consumer runs. Final combined-package
qualification is recorded in the release evidence. These are correctness/crash-safety fixes; no exploit or data
exposure has been demonstrated.

Native inputs are pinned by SHA256
`09b8618810c5788237ebec1c8164c9322d0d65f4d312c41e4908687394647aba`.
All bundles for this release must be rebuilt from those inputs; the older
`v0.1.0-dev` tag and assets remain unchanged.

Keep each archive's `licenses/` directory and the accompanying
`THIRD_PARTY_NOTICES.txt` with redistributed native files. The supplement includes
the Zig MIT notice for the macOS bundle; the Hex installer places it in
application `priv/licenses/` automatically. `THIRD_PARTY.md` records the review
boundaries.

This remains an experimental release, with no target declared release-supported.
Elixir 1.20.0 / OTP 29.0.4 is the qualified runtime. Minimum-system/CPU execution,
broader TSan and Zig allocation coverage, Linux sanitizers and the remaining
implementation-plan gates are not established by these host tests.
