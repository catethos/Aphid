Each archive includes both NIFs, the bridge, engine, required extensions and
license material. The accompanying identities, ELF audits and SHA256SUMS permit
independent review. License-file inclusion is not final attribution clearance.
DuckDB is pinned to 1.4.4. Neither macOS binaries nor bundled-ERTS release archives
are included in this draft.

Execution was on Ubuntu 24.04, glibc 2.39, Elixir 1.20.0, OTP 29.0.4 and GNU
binutils 2.42. Installation requires GNU objcopy, but no Zig or C/C++ compiler.
The engine requires GLIBC 2.38 and GLIBCXX 3.4.32; these symbol requirements do
not prove execution on older systems. Other OTP/binutils versions, CPU minimums,
musl and the separate x86_64-to-ARM64 cross-build gate remain unproved.

The same native bytes subsequently passed the combined source-package consumer
and bundled-ERTS Mix release checks on both architectures in
https://github.com/catethos/Aphid/actions/runs/34199713798.

`docs/local-installation.md`. This draft does not establish an anonymous public
download endpoint or default installation from Hex. Public HTTPS delivery must
be verified after separately authorized publication, before advertising it.
