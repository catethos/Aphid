# Aphid 0.1.2-dev — bundled graph algorithms

ALGO is now statically bundled alongside FTS, vector, and DuckDB. Graph
algorithms run through `Aphid.query/3` without an `INSTALL` or `LOAD` step.
`Aphid.info/1` reports `["algo", "duckdb", "fts", "vector"]`.

Included procedures: PageRank, strongly and weakly connected components,
Kosaraju SCC, Louvain, k-core decomposition, and spanning forest. Project graph
tables with `PROJECT_GRAPH`, then call the algorithm. The extension guide and
`examples/algo.exs` provide a complete PageRank example.

Icebug-backed `GDS_*` functions remain disabled. A pinned build-only patch
removes the unused OpenMP requirement from the standard algorithms; this release
adds no icebug, Arrow, or OpenMP runtime dependency. The five hardening fixes
from `0.1.1-dev` remain included.

The new tests check PageRank, connected-component membership, projection cleanup,
and the documented example. The other bundled algorithms are not individually
qualified by these tests. Release verification is recorded in
`docs/evidence/release-012.md`.

Use `{:aphid, "== 0.1.2-dev"}` with Elixir 1.20.0 / OTP 29.0.4. Native archives
are provided for macOS ARM64 and Linux x86_64/ARM64 with glibc. Keep the bundled
licenses and accompanying notices when redistributing native files.

This is an experimental prerelease. Minimum-system/CPU execution, ALGO sanitizer
coverage, broader TSan/Zig allocation checks, and production support remain open.
Existing releases are unchanged.
