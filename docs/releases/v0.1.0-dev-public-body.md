# Aphid v0.1.0-dev — experimental native validation prerelease

No target is release-supported and no implementation stage is complete. Aphid
is not published to Hex. This prerelease contains native validation archives,
identity/audit records, checksums and retained third-party notice files; it
contains no bundled ERTS release.

Execution is proved only on Ubuntu 24.04/glibc 2.39 and macOS 26.6, using Elixir
1.20.0 / OTP 29.0.4. Linux installation requires GNU objcopy; macOS requires
otool. The Linux engine requires GLIBC 2.38 and GLIBCXX 3.4.32. macOS native
commands declare 13.3; neither those declarations nor ELF requirements prove
minimum-system/CPU execution. Other OTP/binutils, x86_64-to-ARM64 cross-build,
fresh source installation and remaining implementation gates are unproved.
DuckDB stays 1.4.4.

The fixed tag's catalog URLs remain disabled. Public availability alone does not
prove package-default installation. A separately reviewed URL-enabled source
package must pass fresh consumers against the actual repository endpoint on all
three native targets. No silent source fallback or Hex publication is enabled.
